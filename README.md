# 观潮 · A 股行情与模拟交易

面向 HTML5 移动应用开发课程展示的 Vue 3 单页应用。应用使用公开 A 股行情接口展示指数、个股、分时图、K 线和板块数据，并在本机提供虚拟资金交易、自动记账、最近浏览、图片分享、价格提醒、组合压力测试、风险分析和财务诊股。

应用不连接券商，不产生真实下单。行情来自公开市场接口，可能存在短时延迟，不构成投资建议。

## 手机演示

项目已包含构建后的 `dist` 目录：

```powershell
node scripts/serve.mjs
```

终端会显示本机地址和局域网地址。手机与电脑连接同一 Wi-Fi 后，在手机浏览器打开终端中的局域网地址。

如电脑防火墙弹出提示，需要允许 Node.js 在专用网络通信。

修改源码后重新构建：

```powershell
npm install
npm run build
```

开发预览：

```powershell
npm run dev
```

## 实时行情说明

项目通过本地 Node 服务转发公开行情接口，浏览器不直接跨域请求上游服务：

- 指数与个股快照：`/api/quotes`
- 全市场 A 股搜索：`/api/search`
- 当日分时与日 K：`/api/chart`
- 实时板块排名：`/api/sectors`
- 风险、趋势预测与财务诊断：`/api/stock-analysis`
- 好友竞技口令、加入和同步排名：`/api/competition`
- 注册、登录、会话恢复与云端模拟组合：`/api/auth/*`、`/api/user/state`

交易时段内页面会按设定间隔自动刷新；休市时停止轮询，减少无效请求。也可在“我的”中切换为手动刷新。

行情服务采用多层稳定性策略：

- 主行情源失败时自动切换腾讯公开行情接口
- K 线与分时同时保留备用行情源
- 服务端短时缓存，短时间内可返回最近一次有效数据
- 客户端超时、失败重试和部分成功合并
- 接口波动时明确显示“缓存行情”，不会把随机数据伪装成实时数据

公开接口可能受到网络、服务端限流或交易状态影响。遇到短时失败时，可以稍后点击刷新重试。收盘后接口通常返回最近一个交易日的完整行情。

## 推荐演示流程

1. 首页查看上证、深证、创业板实时指数和模拟组合变化。
2. 搜索“招商”“宁德”或任意 A 股代码，打开一个不在默认自选列表中的股票，展示全市场搜索与实时详情。
3. 在详情页切换“分时”和“日 K”，再切换 1 月、3 月、6 月、1 年周期。
4. 设置一条高于或低于目标价的价格提醒。保持页面打开，自动刷新后会触发本地通知。
5. 在交易时段点击“模拟买入”，填写数量和交易理由。成交后进入“模拟盘”查看持仓、盈亏和带笔记的资金流水；当日买入数量会按 T+1 规则锁定。
6. 进入“分析”，查看今日收益贡献、行业暴露，并拖动持仓压力测试滑块。
7. 进入“我的”，切换自动、日间和夜间模式。自动模式在 07:00 至 19:00 使用日间主题。
8. 在股票详情页进入“深度分析”，切换风险分析、趋势预测和财务诊股。
9. 点击详情页分享按钮，自动生成 1080×1350 的行情分享图并调用系统分享或下载。
10. 在模拟盘点击“个人财报”，切换天、周、月、年和历史汇总，并生成财报图片。
11. 在“我的 → 好友竞技”创建 6 位口令，另一台设备输入口令即可加入同步收益率排行榜。
12. 打开观潮助手，尝试“复盘我的持仓”或“检查仓位集中度”。

## 创新功能

- 用真实 A 股行情驱动虚拟资金交易，买卖不产生真实资金风险
- 模拟盘先选股票再下单，支持持仓、自选及全市场搜索
- 自选股票支持搜索添加、移除和持久化，刷新后仍然保留
- 自动记录最近浏览股票，可一键返回或清空
- 模拟交易自动记账，可在下单时记录交易理由
- 按 A 股交易时段限制模拟成交，并执行买入后 T+1 可卖规则
- 组合健康度、收益贡献、行业暴露和五维风险画像
- 可调跌幅的持仓压力测试，直接查看估算资产变化
- 实时价格提醒：到价后在页面内触发，并保存监控记录
- 异动识别、主力资金流向、所属板块表现和换手率分析
- 均线、RSI、MACD、动量和波动率驱动的五行情景参考
- 业绩成长、盈利能力、运营能力、收益质量、财务风险五类财务诊股
- 自动生成行情分享长图，支持系统分享或保存到本地
- 个人财报支持天、周、月、年和历史汇总，逐股展示平均买入价与盈亏
- 个人财报自动生成可保存、可分享的图片
- 好友竞技通过 6 位口令跨设备加入，并滚动同步参赛者收益率排行
- 竞技排行支持总收益、今日收益、总资产和低集中度四个维度
- 排行榜展示累计盈亏、当前仓位、最大单仓和持仓数量
- 点击参赛者可查看其完整持仓、平均成本和逐股盈亏，并生成竞技战绩图
- 服务端账号注册与登录，密码使用加盐哈希保存
- 同一账号在不同手机登录后恢复同一套模拟持仓、自选、提醒、财报与竞技身份
- 登录会话有效期为 30 天，账号数据按用户隔离
- 自动刷新与手动刷新切换，支持 10 / 15 / 30 秒间隔
- 自动、日间、夜间三种主题模式
- 可解释的本地研究助手，不依赖付费 AI API

价格提醒仅在页面打开时运行，关闭页面后不会在后台继续监控。趋势预测和财务评分用于课程展示与风险认知，不是概率保证或收益承诺。

账号、登录会话与竞技房间保存在运行服务电脑的 `.data` 目录中。密码使用 Node.js `scrypt` 加盐哈希后保存，不保存明文密码。手机和电脑需要访问同一个局域网服务，服务关闭时其他设备无法登录或同步排名。游客仍可浏览行情，但参加竞技前必须创建或登录账号。

当前局域网演示服务使用 HTTP，适合可信课堂网络和课程展示。若部署到公网，需要补充 HTTPS、数据库、登录限流、邮箱验证和管理员审计等生产能力。

## 技术说明

- Vue 3 Composition API
- 原生 SVG 分时图与 K 线图
- LocalStorage 保存模拟账户、自选、提醒、交易笔记和主题设置
- Node.js 同源 API 代理、双行情源、短时缓存、超时和失败重试
- Rollup + Vue SFC Compiler 静态构建
- 无真实证券账户、无真实资金交易、无第三方 AI API
